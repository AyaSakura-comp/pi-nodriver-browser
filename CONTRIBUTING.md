# Contributing

1. Fork and clone the repository.
2. Create a virtual environment and install `requirements.txt`.
3. Add or update tests before changing behavior.
4. Run `python3 -m unittest discover -s tests -v`.
5. For browser changes, also run the Chrome/Xvfb integration test documented in `README.md`.
6. Open a focused pull request with the motivation, implementation, and verification evidence.

Do not commit browser profiles, cookies, screenshots containing private data, or Python virtual environments.
