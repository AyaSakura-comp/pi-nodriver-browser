# Contributing

1. Create a virtual environment in `.venv` and install `requirements.txt`.
2. Add or update tests with every behavior change.
3. Run the unit tests (Python and Node, see "Tests" in `README.md`).
4. For browser changes also run the live worker test (`PI_BROWSER_LIVE=1`).
5. Open a focused pull request with the motivation, the change and how it was verified.

Do not commit browser profiles, cookies, screenshots containing private data, or virtual environments.
